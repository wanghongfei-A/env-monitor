# 接线说明（NodeMCU-32S / 38 针）

> 全部接线以**板子丝印**为准。本页的"第几针"是**从 USB 那一头数第 1 针**。
> 改接线前**必须拔 USB**（带电插拔是烧引脚的头号原因）。

## 一、板子针脚位置（按实际丝印确认）

| 丝印 | 位置 | 用途 |
|---|---|---|
| **3V3** | 右排第 19 针（最靠天线那端） | 所有传感器 VCC |
| **GND** | 右排第 6 针 / 左排第 13 针 / 左排第 19 针（任选） | 公共地 |
| **5V** | 右排第 1 针（USB 端） | 蜂鸣器可选用（声音更大） |
| **D4** | 左排第 7 针 | DHT22 数据 |
| **D21** | 左排第 14 针 | I2C SDA |
| **D22** | 左排第 17 针 | I2C SCL |
| **D25** | 右排第 11 针 | 蜂鸣器 I/O |
| **D26** | 右排第 10 针 | 绿 LED |
| **D27** | 右排第 9 针 | 红 LED |

**禁区**：`CLK` `SD0` `SD1` `SD2` `SD3` `CMD`（接内部 flash）、`D0`（boot 引脚，左排第 6 针）。

## 二、面包板电源轨

- 左边缘 **红线（+）** 整条纵向连通 → 接板子的 **3V3**
- 左边缘 **蓝线（−）** 整条纵向连通 → 接板子的 **GND**
- 所有传感器的 VCC 都插红线轨、GND 都插蓝线轨

## 三、逐器件接线

### 1. DHT22（温湿度，4 针模块）

丝印顺序（从左到右）：`GND  NC  DAT  VCC`

| 模块针 | 丝印 | 接到 |
|---|---|---|
| 1 | GND | 蓝线轨（GND） |
| 2 | **NC** | **空着，不接** |
| 3 | DAT | **D4**（左排第 7 针） |
| 4 | VCC | 红线轨（3V3） |

> 板上自带 4.7k/1k 上拉电阻，不用外加。

### 2. BH1750（光照，5 针 I2C）

丝印（按实际，常见）：`VCC  GND  SCL  SDA  ADDR`

| 模块针 | 接到 |
|---|---|
| VCC | 红线轨（3V3） |
| GND | 蓝线轨（GND） |
| SCL | **D22**（左排第 17 针） |
| SDA | **D21**（左排第 14 针） |
| ADDR | **悬空**（默认地址 0x23；接 3V3 会变 0x5C） |

### 3. OLED 0.96"（SSD1306，4 针 I2C）

丝印（按实际，常见）：`VCC  GND  SCL  SDA`

| 模块针 | 接到 |
|---|---|
| VCC | 红线轨（3V3） |
| GND | 蓝线轨（GND） |
| SCL | **D22**（与 BH1750 并联，同一列） |
| SDA | **D21**（与 BH1750 并联，同一列） |

> I2C 是总线：BH1750 和 OLED 的 SDA 接同一根线、SCL 接同一根线，靠地址区分（0x23 / 0x3C）。

### 4. 蜂鸣器模块（3 针，高电平触发）

| 模块针 | 接到 |
|---|---|
| VCC | 红线轨（3V3；声音小可改 5V） |
| GND | 蓝线轨（GND） |
| I/O（S / SIG / IN） | **D25**（右排第 11 针） |

### 5. 两个 LED（各串 1kΩ）

| LED | 接法 |
|---|---|
| 绿 | 长脚（正极）→ **1kΩ** → **D26**；短脚 → GND |
| 红 | 长脚（正极）→ **1kΩ** → **D27**；短脚 → GND |

> LED 长脚是正极。面包板上：长脚插一行、电阻跨到板子引出的那一行，短脚插 GND 轨那一行。

## 四、接完的自检清单（上电前）

- [ ] 3V3 只接到红线轨，**没有**接到 5V
- [ ] 所有 GND 都在蓝线轨
- [ ] DHT22 的 `NC` 针空着
- [ ] BH1750 的 `ADDR` 悬空
- [ ] BH1750 与 OLED 的 SDA 接 **D21**、SCL 接 **D22**（不是反的）
- [ ] 两个 LED 都串了 1kΩ，长脚朝 D26/D27
- [ ] 没有杜邦线跨过面包板中间那道槽（跨过去不通）

## 五、上电后的验证顺序

```
1. I2C 扫描  → 应看到 0x23（BH1750）和 0x3C（OLED）
2. 串口读数  → {"t":17.x,"h":5x.x,"lux":xx} 每 2 秒一行
3. OLED 屏幕 → node01 / 温湿度 / lux / MQTT 状态 / buf 0/200
4. 蜂鸣器    → 把 TEMP_ALARM 临时改到低于室温，应响 + 红灯亮
```

## 六、常见故障对照

| 现象 | 先查 |
|---|---|
| I2C 扫不到 0x23 | SDA/SCL 是否反了、BH1750 VCC 是否在 3V3 |
| 扫不到 0x3C | OLED 的 SDA/SCL 有没有真的并联到同一列 |
| `read failed`（DHT） | DATA 是否在 D4（不是 D2/D0）、VCC 是否 3V3、NC 有没有误接 |
| 读数全 0 或乱跳 | 线虚接（重插到底）；面包板跨槽 |
| 上电板子不启动 | 有短路（多半 3V3 与 GND 接反）→ 立刻拔 USB |
